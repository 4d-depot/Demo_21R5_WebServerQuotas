A test bench, not a real ticketing system. Requests simulate the scenarios below. Quotas are those configured on the 4D server; this page does not change them.

Two budgets: per session for each visitor, and global for the entire server. Default session values apply to new sessions only. Scalable sessions must be enabled.

4 · The traffic spike

Visitors arrive as ticket sales open

Visitors arrive without an account, then customers sign in. Limit the number of concurrent sessions, including guest sessions.

nbSessions: all sessions · nbGuestSessions: guest sessions only.

Once the limit is reached, new sessions can be admitted only when capacity is freed. This is not a per-minute window.

429 + Retry-After: for a per-minute or per-hour limit, wait until the fixed window ends. For sessions and REST entity sets, the header is empty: capacity must be freed.

Clearing the log does not reset the server quotas. REST entity set creations are logged separately and are not included in the request counters above.
